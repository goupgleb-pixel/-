# ORBITA — 3D-сайт на частицах (RU)

Русскоязычный лендинг цифрового агентства в стиле «3D-сайта на частицах»:
ракета из частиц, взрыв в звёздное поле, глобус, галактика и сетка команды.
Фигуры плавно перетекают друг в друга при скролле, частицы отталкиваются от курсора.

Тексты, название и имена в команде — вымышленные заглушки, замените их на свои.

## Запуск

Сборка не нужна. Откройте `index.html` в браузере или поднимите статический сервер:

```
npx http-server . -p 8080
```

Three.js (r128) лежит локально в `js/vendor/`. Шрифты (Oswald, Manrope) подгружаются из Google Fonts.

## Настройка

- `?n=20000` в адресе — число частиц (по умолчанию 42 000, на телефонах 22 000).
- `js/main.js` — формы частиц (`rocketPoint`, `starPoint`, `globePoint`, `galaxyPoint`) и палитра.
- `css/style.css` — вёрстка и типографика; `index.html` — тексты.
